System Theme Sync keeps Paseo's backgrounds and text in sync when macOS changes its appearance while Paseo's theme is set to System.

Paseo 0.15.4 and 0.16.0 can leave a fixed theme class on the page root after switching back to System. That class overrides the operating system's CSS palette while other content continues following the system. This plugin removes only Paseo's known fixed theme classes when the saved theme is System. It observes system appearance, root class changes, settings writes, and returning to the app. It repairs an already inconsistent page when enabled, without reloading the page.

Choose System under Settings → Appearance. A diagnostic page is available in the plugin's settings and through the “系统主题同步：检查并修复” Command Center action. Fixed and contributed themes remain controlled by Paseo. Desktop and web are supported; native mobile clients are unaffected.

This client-only plugin reads the theme field from Paseo's local settings. It observes writes to those settings by transparently wrapping the browser storage setter and removes the wrapper and listeners when disabled. It does not contact a server, read chat content, change macOS preferences, or reload the app. It supports Paseo 0.15.4 through the 0.16 series; later minor versions need compatibility verification. This is a workaround for the root-class issue, not a general repair for arbitrary plugin styles or missed native theme events.
